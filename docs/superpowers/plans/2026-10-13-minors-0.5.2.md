## Global Constraints

- Всё из прежних планов в силе: PE32 i386; импорты только `KERNEL32`, `USER32`, `GDI32`, `msvcrt`; пролог горячего
  патча; откат на dgVoodoo; сборка без предупреждений.
- Каждая подмена метода игры снимает со стека и возвращает то же, что функция игры (`tools/check_hooks.py
  NAME=BYTES:ret`), и вызывает её ровно один раз.
- Версия — `0.5.2`. Картинка не меняется.
- Стиль и коммиты — как раньше (KWEB Team, русские сообщения, трейлер `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`).

## Review Focus

1. **Исключение внутри подмены** (нет памяти): функция игры вызывается ровно один раз, наружу ничего не уходит, окно
   — как в 0.4 — тесты `guarded` (Task 5) и вычитка подмен.
2. **Перетаскивание края окна**: двойники пересобираются один раз, когда масштаб устоится; до того — путь 0.4 — тесты
   `Settled` (Task 4).
3. **Эффекты со значениями вне D3D7** рисуются значениями по умолчанию, ни один ключ не отбрасывается — тест
   `resolveDrawSetup` и перебор (Task 2).
4. **Дыры `CopyFrom`** — только у точек, которые игра копирует: ровно `0xFFFF00FF` по-прежнему оставляет родителя —
   тест (Task 3).
5. **Логотип без двойника** — только вызовы самого затемнения (адреса возврата) — проверка по `objdump` (Task 6).

## Как записаны правки

Как в планах 0.4.x и 0.5.0: «`путь`:» — файл целиком; «В `путь` заменить функцию `НАЧАЛО` целиком:» — функция до
первой строки `}`; «В `путь` после функции `НАЧАЛО` добавить:»; «В `путь` заменить: … на: …» — фрагмент встречается
ровно один раз; «В `путь` добавить в конец:». `.bat` и `.ini` — CRLF на диске, в блоках — LF.

Проверка задачи — скрипт `verify3.sh` (scratch): сборка DLL без предупреждений, `check_dll`, сборка и тесты ядра.

### Task 2: Значения вне D3D7 рисуются значениями по умолчанию (0.4.3, мелочь 2)

Данные эффектов STR не проверяются (states.md §3): в `SRCBLEND`/`DESTBLEND` может прийти 0 или 14–15, в `ZFUNC` и
`CULLMODE` — что угодно. Сейчас такие значения доходят до ключа: файл ключей их отбрасывает (0), рендер строит
конвейер с перечислением D3D12, которого нет в D3D7 (14, 15), а значения от 16 и выше путаются с другими (`& 15`).
`resolveDrawSetup` рисует их как может рендер: сравнение — ALWAYS (как он и строит неизвестное), отсечение — NONE,
множитель — значение по умолчанию D3D7 (ONE для источника, ZERO для приёмника). Перебор состояний расширяется на
такие значения: ни один ключ не отбрасывается.

### Task 3: Дыры CopyFrom как у игры (0.5.0, M1)

Игра копирует каждую точку дочерней, кроме ровно `0xFFFF00FF`. Если скопированная точка при загрузке становится
прозрачной (пятибитный пурпурный, в том числе пурпурный GDI с альфой 0), в окне — дыра. Двойник клал дочернюю
«поверх», и прозрачная точка оставляла родителя. Теперь блоки таких точек берут новые значения родителя — прозрачные.

```cpp
TEST(twin_picture_copy_from_leaves_the_game_holes) {
    // The game copies every child pixel but exactly 0xFFFF00FF; one its upload then makes transparent - magenta in
    // 5 bits, or GDI's magenta with alpha 0 - is a hole in the parent, and so in the twin (0.5.0 review M1).
    std::vector<uint32_t> parent(16, 0xFF0000FF);  // 4 x 4
    TwinPicture p(parent.data(), 4, 4, 2.0);
    const std::vector<uint32_t> kid = {0xFFF807F8, 0x00FF00FF, kMagenta, 0xFFFF0000};  // 2 x 2
    const TwinPicture c(kid.data(), 2, 2, 2.0);
    for (int y = 0; y < 2; ++y)  // what the game's copy does to the parent's pixels
        for (int x = 0; x < 2; ++x) {
            const uint32_t v = kid[size_t(y) * 2 + size_t(x)];
            if (v != kMagenta) parent[size_t(y) * 4 + size_t(x)] = v;
        }
    p.copyFrom(parent.data(), c, 0, 0, 2, 2);
    CHECK_EQ(at(p, 0, 0), 0u);           // 5-bit magenta: a hole
    CHECK_EQ(at(p, 2, 0), 0u);           // GDI's magenta: a hole
    CHECK_EQ(at(p, 0, 2), 0xFF0000FFu);  // exactly 0xFFFF00FF: not copied, the parent stays
    CHECK_EQ(at(p, 2, 2), 0xFFFF0000u);
    CHECK_EQ(p.sync(parent.data(), Rect{0, 0, 4, 4}), 0);
}
```

```cpp
#pragma once
#include <cstdint>

namespace uagfx {

// A value that changes on every frame while something is dragged - the window's scale while its edge is - is taken
// only once it has stayed the same for settleMs; the first value at once (0.5.0 review M2: the twins were rebuilt and
// a log line written on every frame of a resize).
class Settled {
public:
    explicit Settled(uint64_t settleMs) : settle_(settleMs) {}
    // The value as seen at now: true when it is to be taken now.
    bool take(double value, uint64_t now) {
        if (!has_) {
            has_ = true;
            taken_ = value;
            return true;
        }
        if (value == taken_) {
            pending_ = false;
            return false;
        }
        if (!pending_ || value != candidate_) {
            pending_ = true;
            candidate_ = value;
            since_ = now;
        }
        if (now - since_ < settle_) return false;
        taken_ = value;
        pending_ = false;
        return true;
    }
    double taken() const { return taken_; }

private:
    uint64_t settle_;
    bool has_ = false;
    double taken_ = 0.0;
    bool pending_ = false;
    double candidate_ = 0.0;
    uint64_t since_ = 0;
};

}  // namespace uagfx
```

### Task 5: Исключение из подмены не уходит в кадры игры (0.5.0, M3)

Подмены работают внутри кадров MSVC игры: исключение C++ из драйвера (нет памяти — карты, кеш букв, буферы
текселей, данные области) не должно их пересечь. Новый `guarded` выполняет работу и отдаёт исключение обработчику.

в 0.4 (`lost`, одна строка в лог). Функция игры вызывается ровно один раз. `picture()` вставляет картинку в таблицу
первой: если сбой — после, `drop` находит её целиком.

```cpp
namespace uagfx {

// Runs work; an exception from it goes to onFailure instead of up, and nothing leaves this function (0.5.0 review
// M3): the crisp text hooks run inside the game's MSVC frames, which a C++ exception from the driver must never
// cross. true when work finished.
template <typename Work, typename Failure>
bool guarded(Work&& work, Failure&& onFailure) noexcept {
    try {
        work();
        return true;
    } catch (...) {
        try {
            onFailure();
        } catch (...) {
        }
        return false;
    }
}

}  // namespace uagfx
```
