# MCP in the client - implementation plan

> Executed inline (the owner: «все в инлайн режиме»; betas without stopping).

**Goal:** an MCP server in the driver (off by default, 127.0.0.1) - Claude drives the client: state, screenshot,
chat (@warp), walk, the 3D view, Pause, the photo mode, a settings line.

**Spec:** docs/superpowers/specs/2026-11-20-mcp-design.md

## Tasks

1. core/mcp (+ tests): HTTP parsing (head, Content-Length, 1 MB at most), the checks (Origin refused, Host
   127.0.0.1/localhost only), JSON-RPC (initialize with the version agreed, ping, tools/list, tools/call, a
   notification -> 202, errors -32700/-32600/-32601/-32602), the tools' table with their schemas, the arguments'
   checks, a result's content (text, a JPEG image).
2. Settings [mcp] enabled (0) and port (8770): config, schema, live config, catalogue (Diagnostics), strings.
3. win/mcp_server: the socket thread (127.0.0.1:port, one connection at a time), the calls queued for the game's
   thread and answered (10 s at most); started and stopped by [mcp] enabled live.
4. win tools: state, screenshot (the present's PNG -> WIC: 1280 wide JPEG), chat (chatwheel's sendLine), walk (the
   pad session's own 0x00a7), view (view3dwin ask + its look), pause / photo (Context), setting (editIniFile).
5. Beta: gate, notes, ship; the owner's tunnel line and the first checks.

## Ledger
- Task 1: core/mcp + 8 host tests (678d9bce).
- Task 2: [mcp] enabled (0) / port (8770) in Diagnostics, live (ae9fca83) + a config test.
- Tasks 3-4: win/mcp_server (its thread, Winsock from the game's ws2_32 - the driver still imports GDI32, KERNEL32,
  msvcrt, USER32 alone; SRWLOCK, no std::mutex), win/context_mcp (the tools), Context::toggleCompare (the key's and
  the MCP's), pad Session::request + runtime::walkTo (+ a session test), chatwheelwin::sendCommand, view3dwin look /
  setLook (a look asked with its view put at the view's first build).
- Ruling: the screenshot as PNG, not JPEG - the renderer's own shot spec makes it N times smaller (`path|/N`), so no
  WIC/COM in the driver; 1280 wide is 0.5-1.5 MB, enough through the tunnel.
