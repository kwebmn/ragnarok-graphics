# uaUI - the windows with drag and drop live, then the big ones (plan and ledger)

Owner 2026-11-10: «нпчинай нонстоп без остановки» on the order 1 -> 2 -> 3 (4, the login screens, last, with the
owner's checks). Betas only, the gate before each (gship.sh).

1. The drop protocol: what is under a point of a live window from RmlUi's own layout (uikit/hits: data-hit and
   data-index, the element at the point walked up). RmlUi built for the host too (uagfx_rmlui, uagfx_uikit), the
   built-in theme moved to core (core/ui_theme_css) - the live windows' markup laid out in the host tests
   (tests/rml_host: a stand-in font, no drawing).
2. The windows with drag and drop: «Речі», «Склад», «Візок» (one grid, uikit/item_grid_live), then «Обмін»,
   «Спорядження», «Навички», the homunculus, the mercenary.
3. The NPC shop, stats (Alt+A), the guild.
4. The login screens - only with the owner's checks.

Way (the same for every window): the window's markup laid out by RmlUi (flexbox), its model from the window's own
state; refit - RmlUi's boxes put into the window's core layout after each layout, so its own hit test, clicks, drags,
drops into other windows, flashes and the pad's places fall where the cells are drawn. The windows' input code stays
as tested; only the boxes come from the library.
