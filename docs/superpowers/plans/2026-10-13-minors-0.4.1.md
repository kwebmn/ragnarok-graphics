**Goal:** закрыть все отложенные мелочи ревью 1B (M4, M5, M6, M8, M9) и этапа 3 (M1, M2, M3, M4, M6, M7) — выпуск

**Architecture:** чистая логика — в ядре с тестами на Linux (ключ конвейера и файл ключей, ключ пары сэмплеров, порядок

**Tech Stack:** C++17, MinGW-w64 i686 GCC 12, Direct3D 12 (SM 5.0), тесты на Linux.

**Spec:** основа — ревью: 1B (финальное ревью плана 1B, мелочи M4–M9) и этапа 3 (ledger этапа 3: «Final: minor
(deferred)»); спецификации `docs/superpowers/specs/2026-10-13-uaro-graphics-design.md` и
`docs/superpowers/specs/2026-10-13-stage3-resolution-design.md` в силе. Справка: `docs/research/states.md`.

## Мелочи и задачи

| Мелочь | Что не так | Задача |
|---|---|---|
| 1B M8 | конвейер строится при первом рисовании с новыми состояниями — эффект подтормаживает | 1, 2 |
| 1B M6 | ключ пары сэмплеров — хеш без проверки совпадения: возможна чужая пара | 3 |
| 1B M4 | полный кэш сэмплеров перезапускает список посреди записи; вершины остаются в чужом слоте | 4 |
| 1B M5 | кольцо GPU-дескрипторов переписывается без проверки, свободно ли оно | 4 |
| 1B M9 | `monitor = N` считает мониторы в порядке Windows, не от основного | 5 |
| 3 M1 | размер swap chain, не созданный однажды, больше не пробуется — окно замирает | 6 |
| 3 M2 | после потери устройства цикл игры крутит ядро на 100 % | 7 |
| 3 M3 | сбой создания вспомогательной текстуры оставляет `setTarget` с устаревшими дескрипторами | 7 |
| 3 M6 | копирование части кадра берёт крайние точки из-за прямоугольника | 8 |
| 3 M7 | изменение размера окна пишет в лог по две-четыре строки на кадр | 9 |
| 3 M4 | в логе не видно, что калибровка прошла до первого кадра в масштабе | 9 |

## Global Constraints

- Всё из прежних планов в силе: PE32 i386; импорты только `KERNEL32`, `USER32`, `GDI32`, `msvcrt` (D3D12, DXGI,
  `d3dcompiler_47` — через `LoadLibrary`/`GetProcAddress`); пролог горячего патча у `DirectDrawCreateEx`; откат на
  dgVoodoo при любой ошибке запуска рендера; сборка без предупреждений.
- Версия — `0.4.1`. Картинка не меняется: исправления — надёжность и лог.
- HLSL здесь не компилируется: только SM 5.0; синтаксис проверяется glslang (как в этапе 3).
- Имена в `src/core` не совпадают с макросами Win32.
- Файл ключей конвейеров — `uaro-graphics-pipelines.txt` рядом с логом; первая строка `uaro-graphics pipelines 1`.
- Стиль и коммиты — как раньше (KWEB Team, русские сообщения, трейлер `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`).

## Review Focus

1. **Порядок в `draw()` и `blit()`.** Новый список (полный кэш сэмплеров, полный отрезок кольца) начинается только до
   первой записи рисования; геометрия записи загружается заново, если с её загрузки был `submit`. Проверка — сборка и
   вычитка (GPU-код на Linux не запустить); у пользователя — игра без мусора и падений.
2. **Файл ключей конвейеров**: битый, пустой, от другой версии, нет прав на запись (Program Files) — игра идёт как
   раньше. Тесты разбора — Task 1; запись — Task 2.
3. **Сдерживание строк лога** не должно терять последнее состояние: после изменения размера окна в логе есть итоговая
   строка `scale:`. Тест — Task 9.
4. **Ограничение выборки прямоугольником** в копированиях не меняет показ всего кадра (на краях то же, что CLAMP). Код — Task 8.
5. **`monitor = 1`** при двух мониторах — второй, при одном — основной. Тест — Task 5.

## Как записаны правки

Код в задачах — точный, применяется дословно. Формы (за каждой — блок кода, у замены — два):
- `` `путь`: `` — новый файл (или файл целиком);
- «В `путь` заменить функцию `НАЧАЛО` целиком:» — многострочная функция, первая строка которой начинается с
  `НАЧАЛО`, до первой строки, равной `}`, заменяется блоком;
- «В `путь` после функции `НАЧАЛО` добавить:» — пустая строка и блок после этой функции;
- «В `путь` заменить: … на: …» — фрагмент встречается в файле ровно один раз;
- «В `путь` добавить в конец:».
В `.bat` и `.ini` строки — CRLF (блоки в плане — с обычными переводами строк).

```cpp
#pragma once
#include <cstdint>
#include <string>
#include <vector>

#include "core/states.hpp"

namespace uagfx {

// The pipeline state a draw needs; packed, it is the key the renderer caches pipelines by. The keys met in a session
// are saved and their pipelines built at the next start, so an effect does not stutter the first time it is drawn
// (1B review M8).
struct PipelineKey {
    bool zEnable = false;
    bool zWrite = false;
    uint8_t zFunc = 0;     // d3d7::CMP_*
    uint8_t cull = 0;      // d3d7::CULL_*
    bool blend = false;
    uint8_t srcBlend = 0;  // d3d7::BLEND_*
    uint8_t dstBlend = 0;
    bool twoUv = false;    // FVF_TL2: a second UV set
    bool operator==(const PipelineKey& o) const;
};

PipelineKey pipelineKey(const DrawSetup& s, uint32_t fvf);
uint64_t packPipelineKey(const PipelineKey& k);
PipelineKey unpackPipelineKey(uint64_t v);

// The saved keys: pipelineKeysHeader(), then pipelineKeyLine() per key. Lines that are not hex are skipped; a file
// without this header (another version, or none) gives nothing.
std::vector<uint64_t> parsePipelineKeys(const std::string& text);
std::string pipelineKeysHeader();
std::string pipelineKeyLine(uint64_t v);

}  // namespace uagfx
```

`src/core/pipeline_key.cpp`:
```cpp
#include "core/pipeline_key.hpp"

#include <cstdio>
#include <sstream>

#include "core/d3d7.hpp"

namespace uagfx {

bool PipelineKey::operator==(const PipelineKey& o) const {
    return zEnable == o.zEnable && zWrite == o.zWrite && zFunc == o.zFunc && cull == o.cull && blend == o.blend &&
           srcBlend == o.srcBlend && dstBlend == o.dstBlend && twoUv == o.twoUv;
}

PipelineKey pipelineKey(const DrawSetup& s, uint32_t fvf) {
    PipelineKey k;
    k.zEnable = s.zEnable;
    k.zWrite = s.zWrite;
    k.zFunc = uint8_t(s.zFunc & 15);
    k.cull = uint8_t(s.cull & 3);
    k.blend = s.blend;
    k.srcBlend = uint8_t(s.srcBlend & 15);
    k.dstBlend = uint8_t(s.dstBlend & 15);
    k.twoUv = fvf == d3d7::FVF_TL2;
    return k;
}

uint64_t packPipelineKey(const PipelineKey& k) {
    return uint64_t(k.zEnable) | uint64_t(k.zWrite) << 1 | uint64_t(k.zFunc & 15) << 2 | uint64_t(k.cull & 3) << 6 |
           uint64_t(k.blend) << 8 | uint64_t(k.srcBlend & 15) << 9 | uint64_t(k.dstBlend & 15) << 13 |
           uint64_t(k.twoUv) << 17;
}

PipelineKey unpackPipelineKey(uint64_t v) {
    PipelineKey k;
    k.zEnable = (v & 1) != 0;
    k.zWrite = (v >> 1 & 1) != 0;
    k.zFunc = uint8_t(v >> 2 & 15);
    k.cull = uint8_t(v >> 6 & 3);
    k.blend = (v >> 8 & 1) != 0;
    k.srcBlend = uint8_t(v >> 9 & 15);
    k.dstBlend = uint8_t(v >> 13 & 15);
    k.twoUv = (v >> 17 & 1) != 0;
    return k;
}

std::string pipelineKeysHeader() { return "uaro-graphics pipelines 1\n"; }

std::string pipelineKeyLine(uint64_t v) {
    char line[24];
    std::snprintf(line, sizeof line, "%llx\n", static_cast<unsigned long long>(v));
    return line;
}

std::vector<uint64_t> parsePipelineKeys(const std::string& text) {
    std::vector<uint64_t> keys;
    std::istringstream in(text);
    std::string line;
    bool header = false;
    while (std::getline(in, line)) {
        if (!line.empty() && line.back() == '\r') line.pop_back();
        if (!header) {
            if (line + "\n" != pipelineKeysHeader()) return keys;
            header = true;
            continue;
        }
        if (line.empty() || line.size() > 16 || line.find_first_not_of("0123456789abcdef") != std::string::npos)
            continue;
        keys.push_back(std::stoull(line, nullptr, 16));
    }
    return keys;
}

}  // namespace uagfx
```

```cpp
ID3D12PipelineState* Renderer::Impl::pipelineForKey(uint64_t key) {
    auto it = pipelines.find(key);
    if (it != pipelines.end()) return it->second;
    const PipelineKey k = unpackPipelineKey(key);

    // FVF 0x1C4 has one UV set: TEXCOORD1 reads the same bytes as TEXCOORD0.
    const D3D12_INPUT_ELEMENT_DESC layout[5] = {
        {"POSITION", 0, DXGI_FORMAT_R32G32B32A32_FLOAT, 0, 0, D3D12_INPUT_CLASSIFICATION_PER_VERTEX_DATA, 0},
        {"COLOR", 0, DXGI_FORMAT_B8G8R8A8_UNORM, 0, 16, D3D12_INPUT_CLASSIFICATION_PER_VERTEX_DATA, 0},
        {"COLOR", 1, DXGI_FORMAT_B8G8R8A8_UNORM, 0, 20, D3D12_INPUT_CLASSIFICATION_PER_VERTEX_DATA, 0},
        {"TEXCOORD", 0, DXGI_FORMAT_R32G32_FLOAT, 0, 24, D3D12_INPUT_CLASSIFICATION_PER_VERTEX_DATA, 0},
        {"TEXCOORD", 1, DXGI_FORMAT_R32G32_FLOAT, 0, k.twoUv ? 32u : 24u, D3D12_INPUT_CLASSIFICATION_PER_VERTEX_DATA, 0},
    };
    D3D12_GRAPHICS_PIPELINE_STATE_DESC p{};
    p.pRootSignature = root;
    p.VS = {drawVs->GetBufferPointer(), drawVs->GetBufferSize()};
    p.PS = {drawPs->GetBufferPointer(), drawPs->GetBufferSize()};
    D3D12_RENDER_TARGET_BLEND_DESC& b = p.BlendState.RenderTarget[0];
    b.BlendEnable = k.blend ? TRUE : FALSE;
    b.SrcBlend = D3D12_BLEND(k.srcBlend ? uint32_t(k.srcBlend) : uint32_t(d3d7::BLEND_ONE));
    b.DestBlend = D3D12_BLEND(k.dstBlend ? uint32_t(k.dstBlend) : uint32_t(d3d7::BLEND_ZERO));
    b.BlendOp = D3D12_BLEND_OP_ADD;
    b.SrcBlendAlpha = D3D12_BLEND_ONE;  // the target's alpha is never read (DESTALPHA reads 1): keep it simple
    b.DestBlendAlpha = D3D12_BLEND_ZERO;
    b.BlendOpAlpha = D3D12_BLEND_OP_ADD;
    b.LogicOp = D3D12_LOGIC_OP_NOOP;
    b.RenderTargetWriteMask = D3D12_COLOR_WRITE_ENABLE_RED | D3D12_COLOR_WRITE_ENABLE_GREEN | D3D12_COLOR_WRITE_ENABLE_BLUE;
    p.SampleMask = UINT_MAX;
    p.RasterizerState.FillMode = D3D12_FILL_MODE_SOLID;
    p.RasterizerState.CullMode = k.cull >= d3d7::CULL_NONE && k.cull <= d3d7::CULL_CCW ? D3D12_CULL_MODE(k.cull)
                                                                                        : D3D12_CULL_MODE_NONE;
    p.RasterizerState.FrontCounterClockwise = FALSE;
    p.RasterizerState.DepthClipEnable = TRUE;
    p.DepthStencilState.DepthEnable = k.zEnable ? TRUE : FALSE;
    p.DepthStencilState.DepthWriteMask = k.zWrite ? D3D12_DEPTH_WRITE_MASK_ALL : D3D12_DEPTH_WRITE_MASK_ZERO;
    p.DepthStencilState.DepthFunc = k.zFunc >= d3d7::CMP_NEVER && k.zFunc <= d3d7::CMP_ALWAYS
                                        ? D3D12_COMPARISON_FUNC(k.zFunc)
                                        : D3D12_COMPARISON_FUNC_ALWAYS;
    p.InputLayout = {layout, 5};
    p.PrimitiveTopologyType = D3D12_PRIMITIVE_TOPOLOGY_TYPE_TRIANGLE;
    p.NumRenderTargets = 1;
    p.RTVFormats[0] = DXGI_FORMAT_B8G8R8A8_UNORM;
    p.DSVFormat = DXGI_FORMAT_D32_FLOAT;
    p.SampleDesc.Count = 1;
    ID3D12PipelineState* pso = nullptr;
    if (FAILED(device->CreateGraphicsPipelineState(&p, __uuidof(ID3D12PipelineState), reinterpret_cast<void**>(&pso)))) {
        LOG_ERROR("pipeline for key 0x%llx failed", static_cast<unsigned long long>(key));
        pso = nullptr;
    }
    pipelines.emplace(key, pso);  // a failure is remembered too: no retry every draw
    if (pso && !pipelineFile.empty()) {  // built at the next start (1B review M8); a folder without rights: no list
        std::ofstream f(pipelineFile, std::ios::binary | std::ios::app);
        f << pipelineKeyLine(key);
    }
    return pso;
}
```

```cpp
void Renderer::preparePipelines(const std::string& file) {
    Impl& m = *impl_;
    std::string text;
    win::readTextFile(file, text);
    const std::vector<uint64_t> keys = parsePipelineKeys(text);
    // Written anew: a list from another version or with broken lines starts clean, keys listed twice once.
    const std::set<uint64_t> unique(keys.begin(), keys.end());
    std::string clean = pipelineKeysHeader();
    for (const uint64_t k : unique) clean += pipelineKeyLine(k);
    std::ofstream(file, std::ios::binary | std::ios::trunc) << clean;
    LARGE_INTEGER freq, t0, t1;
    QueryPerformanceFrequency(&freq);
    QueryPerformanceCounter(&t0);
    unsigned ready = 0;
    for (const uint64_t k : unique)
        if (m.pipelineForKey(k)) ++ready;
    QueryPerformanceCounter(&t1);
    m.pipelineFile = file;  // from now on every new pipeline is added
    LOG_INFO("pipelines: %u of %u saved ones prepared in %.0f ms", ready, unsigned(unique.size()),
             double(t1.QuadPart - t0.QuadPart) * 1000.0 / double(freq.QuadPart));
```

### Task 4: Новый список команд — только до того, как рисование что-то записало (1B M4, M5)

Два места начинали новый список команд не вовремя:
- **M4.** Полный кэш сэмплеров перезапускал список посреди `draw()` и `blit()`. Остальные рисования записи читали
  вершины из буфера прежнего слота, а тот слот снова пускался в дело, пока новый список мог их читать.
- **M5.** Кольцо GPU-дескрипторов текстур при переполнении начиналось сначала, не проверяя, закончены ли списки,

- У каждого слота своя половина кольца. Она свободна, когда закончился прежний список этого слота — `begin()`

  слот нового списка.

```cpp
    if (nextSampler + 2 > kSamplerCount &&

        waitIdle();
        samplerPairs.clear();
        nextSampler = 0;
        if (!begin()) return false;
    }
    if (ringSrv + 2 > kRingPerSlot) {
        submit();
        if (!begin()) return false;
    }
    return open;
}
```

```cpp
// Something that failed is tried again after a pause: not on every frame, and not never (stage 3 review M1 - a swap

class RetryTimer {

    void failed(uint64_t now) {
```

```cpp
#pragma once
#include <cstdint>

namespace uagfx {

// A log line about something that may change every frame (a window being resized) is written at most once per
// interval, and the last state still once things settle (stage 3 review M7).
class Throttle {
public:
    explicit Throttle(uint64_t intervalMs) : interval_(intervalMs) {}
    // A change at now: true = write it now; false = due() writes the state later.
    bool changed(uint64_t now) {
        if (!wrote_ || now - last_ >= interval_) {
            mark(now);
            return true;
        }
        pending_ = true;
        return false;
    }
    // On every frame: true = a change was held back and its time has come; write the current state.
    bool due(uint64_t now) {
        if (!pending_ || now - last_ < interval_) return false;
        mark(now);
        return true;
    }

private:
    void mark(uint64_t now) {
        last_ = now;
        wrote_ = true;
        pending_ = false;
    }
    uint64_t interval_;
    uint64_t last_ = 0;
    bool wrote_ = false;
    bool pending_ = false;
};

}  // namespace uagfx
```
