# Интерфейс uaRO: раскладка старой игры, наш вид, две темы — дизайн

Статус: одобрено владельцем 27.11.2026 («да»). Концепт с картинками всех окон в обеих темах:
https://uaro.kiev.ua/docs/item-windows/ (kozak `web/docs/item-windows/`). Все решения ниже — решены владельцем 27.11.

## Зачем

Владелец 25.11: «у нас есть глюки с интерфейсом, особенно с покупкой, передачей вещей. и новый интерфейс хотя и
выглядит современно но имеет набор проблем и для новых игроков не очень удобен». 27.11: «они привыкли к старым
интерфейсам, надо продумать такой интерфейс в котором он был как старый но с новыми возможностями и он должен не
глючит».

Жалобы игроков: R-DBGBHJ «в новом интерфейсе не могу купить», R-AR8CRT «не могу прочитать описание предметов»,
R-WP985Q «непонятные символы в карточке», R-WVP27C «долго грузится склад». С середины октября — 99 исправлений, 22 из
них про перенос вещей; причина — два хозяина у каждого действия (наше окно и окно игры).

## Цели

- Все наши окна — по раскладке и поведению старого клиента (kRO 2007): где что лежит, перетаскивание, двойной клик,
  правый клик — описание, окно «скільки»; привычные новшества сохраняются.
- Новое видно новичку: кнопки и строка-подсказка клавиш внизу окна, а не только скрытые клавиши.
- У действия с вещью один хозяин — наш слой: действие уходит нашим пакетом, результат — из ответа сервера.
- Две темы — тёмная и светлая — для всего интерфейса, включая основной экран; новичкам по умолчанию тёмная; цвета по
  группам и свой цвет акцента в полном режиме.

## Не цели

- Сервер игры не меняем (другой программист).
- «Современный» вид не делаем.

## Чего нельзя допустить

- Потерять или удвоить вещь или зени из-за нашего окна.
- Две копии правды: окно игры и наше одновременно действуют над одной вещью.
- Новичок не находит действие, которое было в старом окне.
- Настройка темы в трёх местах расходится (в игре одно, в лаунчере другое).

## Ограничения

- Клиент kRO Sakexe 2007-05-07. Номер и длина каждого пакета — из `/root/uAthena/db/packet_db.txt` для версии нашего
  клиента и сверяются с журналом отправок самой игры. Ядро уже есть: `core/item_packets`, `core/item_state`,
  `core/item_actions`, `win/item_net` (бета 3.0.24-beta.4–.18).
- Окна — uaUI (RmlUi), разметка RML руками, проверка парсером; ширины в % — border-box; без SetProperty каждый кадр.
- Тексты на трёх языках в `core/settings/strings.cpp`; слова окон — на языке игры.
- Каждое окно — своя галка; новое сначала у тестеров («Перевіряємо зараз»), всем — после проверки и слова владельца.
- Пад управляет каждым окном.
- Слабые видеокарты: без размытия фона и тяжёлых теней.
- Размер — от масштаба интерфейса.

## Подходы (окна вещей)

1. **А. «Как в игре, только чётко»** — картинки старых окон из файлов клиента. Отброшен владельцем.
2. **Б. Старая раскладка, наш вид** — **выбран.** Расположение и поведение старых окон, цвета и шрифты нашего
   интерфейса, две темы. Потом то же правило — для остальных окон.
3. **В. Окна самой игры + наша полоска кнопок** — отброшен: мелко, мягко, новое не помещается.

## Решено владельцем 27.11

- Способ Б; вкладки — наши шесть (усе / витратне / спорядж. / карти / різне / обране) вертикально слева; размер — от
  масштаба интерфейса; слова — на языке игры.
- Остальные окна (навыки, характеристики, NPC, группа, гильдия) — «подвести к раскладке старой игры, но постараться
  оставить новшества».
- Темы тёмная и светлая — для всего интерфейса, основной экран тоже («делай тоже»); новичкам — тёмная. Выбор — в
  Alt+O («Вигляд» → «Тема інтерфейсу»), в лаунчере и в программе настроек.
- Полный режим: тема по группам («какую групу каким цветом рисовать … попроще»): основной экран, чат, окна вещей,
  торговля (отдельная группа), остальные окна, настройки — у каждой «як усе / темна / світла». Цвет акцента — четыре
  готовых и «свій колір» (палитра + код цвета) — «как доп опция чтобы он цвет сам мог подобрать».
- Продажа NPC: «обране» в продажу не попадает; вещь с картой — всегда спрашиваем; заточка +5 и выше — спрашиваем.
- Цены с рынка сайта (в «Відкрити лавку» и в картке): программа настроек раз в день скачивает файл средних цен.
- Обмін: красной рамкой — то, что другой положил (и зени, что выставил) за 5 с до своего «Готово» (в RO вещь из обмена
  не убрать, только отменить обмен).
- Моя лавка: последний покупатель и тихий звук при продаже.
- Скільки штук: кнопки 1 / 10 / половина / усе.
- Навички: описание — отдельным окошком по ПКМ (как в старой игре).
- Разговор с NPC: выбор — отдельным списком, который ведут мышь (наведение, колесо, клик), клавиатура (↑ ↓, 1–5,
  Enter, Esc) и геймпад (хрестовина, A, B).

## Общие детали (один раз для всех окон)

- Заголовок: название на языке игры, клавиша окна (Alt+E…), ×. Строка-подсказка клавиш внизу окна.
- Вертикальные вкладки слева (окна вещей), поле поиска, ячейки с числом, пометка «нове».
- Нижняя полоса: вес / места / зени с полоской заполнения (красная, когда почти полно).
- Кнопки: главная (акцент), обычная, опасная (красная рамка).
- Список строк: значок, название, подпись, цена справа, «− N +».
- Окно «скільки» и картка вещи — общие для всех окон.

## Окна вещей

Как в старом → новое. Пакеты — семантика; номера по правилу из «Ограничений».

- **Речі + Спорядження.** Сетка, вкладки; «Спорядження» вплотную слева, двигаются вместе (решено 31.10); слоты по
  местам старого окна, фигурка, стрелы, комплекты 1/2/3. Новое: поиск, «нове», вес и зени, подсказка клавиш.
  Действия: использовать, надеть, снять, выбросить — нашими пакетами (последний этап «через пакеты»).
- **Склад.** То же окно, что «Речі». Новое: выбор нескольких и «Забрати вибране (N)», Alt+ПКМ — вся пачка, места.
  Пакеты есть (0x0094 / 0x00f7 / 0x0193).
- **Візок.** То же окно; вес тележки, «Відкрити лавку». Новое: красная полоса, когда почти полна; склад ↔ візок
  напрямую. Пакеты есть (0x0126–0x0129).
- **Крамниця NPC: купити.** Список и кошик рядом. Новое: поиск, клик 1 / Shift 10 / ПКМ картка, «залишиться», вес
  после покупки, отказ с причиной. Пакеты есть (0x00c8 / 0x00ca).
- **Крамниця NPC: продати.** Ваши вещи слева, что продаёте справа. Новое: защита продажи (см. решения), вся вкладка
  «Різне» кнопкой, двойной клик — вся пачка. Пакеты есть (0x00c9 / 0x00cb).
- **Лавка торговця.** Список и кошик. Новое: ПКМ — картка с картами и заточкой, вес после покупки, отказ с причиной.
  Пакеты есть (0x0134 / 0x0135).
- **Відкрити лавку.** Тележка слева, лавка справа: название, цена, количество, «N з M місць». Новое: цена с рынка
  сайта, цены запоминаются. Пакет открытия лавки — новый.
- **Моя лавка.** Что выставлено, «Закрити лавку». Новое: продано N из M, заработано с налогом сервера (2 %,
  `vending_tax 200`), последний покупатель (сервер шлёт «%s has bought your item(s).», `buyer_name: yes`), звук.
  Пакеты: отчёт о продаже, закрытие лавки — новые.
- **Обмін.** «Віддаєте» | «отримуєте», зени под каждым, «Готово» → «Обмін». Новое: красная рамка (см. решения),
  картка по наведению, зени с пробелами. Пакеты обмена — новые.
- **Скільки штук.** Число, Enter / Esc; кнопки 1 / 10 / половина / усе; предел по весу и месту. Уже есть свой режим
  (`askcardwin::askCount`, 3.0.24-beta.7).
- **Картка речі.** Картинка, свойства, описание, гнёзда. Новое: что даёт каждая карта, свободные гнёзда, цена у NPC и
  на рынке сайта.
- **Вибір речі** (дописано при проверке): списки, которые открывает сервер — лупа (опознать), стрелы (Arrow
  Crafting), вставить карту, ремонт, заточка. В старой игре — маленький список; у нас уже есть свои окна
  (`[interface] picks`, `win/pick_card`). Новое: значки, поиск, картка по ПКМ. Действие — ответом в тот же список
  (пакеты выбора — по правилу из «Ограничений»).

## Остальной интерфейс (раскладка старой игры, новшества сохраняем)

- **Основной экран.** Блок персонажа (старое «Basic Info»), миникарта, панель F1–F9, чат — на старых местах; обе
  темы. Сохраняем: регенерация, ATK/DEF/FLEE/ASPD, полоски опыта, кнопки окон; режим боя панели (ряды Q/A/Z), поиск
  в чате (Ctrl+F), метки и карта мира у миникарты. В ту же группу и обе темы входят остальные части экрана: баффы,
  карточка цели, «Боси» и таймеры MVP, «Полювання», подсказки клавиш, тост «+N речі».
- **Навички (Alt+S).** Узкий список: значок, название, уровень, SP, стрелка «+1»; очки внизу; описание — отдельным
  окошком по ПКМ. Сохраняем: вкладки профессий, «План», «Дерево».
- **Характеристики (Alt+A).** Две колонки: STR…LUK «база + бонус», стрелка и цена; атака, маг. атака, влучність,
  крит, захист, маг. захист, ухил, ASPD, очки, гильдия. Сохраняем: «что даст +1», формулы.
- **Разговор с NPC.** Слова NPC в широком окне («Закрити»); выбор — отдельный список (см. решения).
- **Група.** Список: лидер, карта, HP; «Запросити», досвід, «Вийти». Сохраняем: полоски HP, «не в грі».
- **Гільдія.** Вкладки сверху: інформація, учасники, посади, навички, вигнання, оголошення; герб и данные. Сохраняем:
  кто онлайн, опыт полоской.
- **Вибір персонажа.** Карточки, «Увійти», «Створити», «Видалити», «Назад». Сохраняем: карусель, HP/SP и параметры.
- **Вхід и створення персонажа** (дописано при проверке): тоже в обеих темах; выбор характеристик при создании — уже
  как в старом клиенте (R-VE23RV, вариант A, 3.0.22-beta.46).

## Темы

- Одна настройка на трёх местах — Alt+O, лаунчер, программа настроек — одно значение в `uaro-graphics.ini`;
  поменяли в одном — видно в других.
- Существующая `[interface] theme` (`core/ui_theme`: standard | classic | contrast) получает значение «світла»;
  тёмная (standard) — по умолчанию. Цвета всех окон проходят через тему (`themedCss`).
- Группы: основной экран, чат, окна вещей, торговля, остальные окна, настройки — у каждой «як усе / темна / світла»
  (полный режим Alt+O и «Докладний» программы настроек).
- Акцент: золотой / синий / зелёный / червоний / «свій колір» (палитра 3×10 + поле «#RRGGBB»).
- Лаунчер: «Інтерфейс — Темний / Світлий» рядом с «Вигляд гри»; сам лаунчер остаётся тёмным.
- Светлая: фон окна #f6f8fc, ячейки белые, линии #cbd3e2, текст #181c26, акцент синий #2f5fd0.

## Обязательно для всех окон (дописано при проверке)

- **Все знаки есть в шрифте.** Жалоба R-WP985Q «непонятные символы в карточке» — похоже, знаки, которых нет в шрифте
  интерфейса (в эскизах так пропали ★ ▲ ▾). Тест в ядре: каждый символ каждой строки окон есть в шрифте; стрелки,
  звёзды и треугольники — рисованные значки, не буквы.
- **«Скинути до стандартних»** сбрасывает и тему, и группы, и акцент.
- **Каждое окно — своя карточка в «Перевіряємо зараз»** на время проверки.
- **Пад и клавиатура — и для новых элементов:** кнопки групп, палитра «свій колір», список NPC.
- **Отчёт об ошибке** несёт тему, группы и акцент (они в `uaro-graphics.ini`, который уже прикладывается).

## Цены с рынка сайта

- Сайт отдаёт файл средних цен (номер вещи → средняя цена, число сделок). Программа настроек скачивает его раз в день
  в папку данных; игра только читает файл (в ddraw.dll нет сети). Нет файла или вещи — строки «ринок сайту» нет.
- Данных мало (проверено 27.11): на рынке сайта 164 сделки по 96 вещам за пять месяцев и 80 вещей в продаже сейчас;
  сервер игры пишет в базу только лавки автоторговли (сейчас одна, 3 вещи). Значит, цена найдётся для сотни-двух
  ходовых вещей. Предложение: показывать «на ринку сайту від X z (N пропозицій)» по текущим лотам и среднюю — только
  при трёх сделках и больше.

## Порядок

1. Проверить в игре пакеты «Складу», «Візка», «Крамниці», «Лавки».
2. Темы: светлая в `core/ui_theme`, группы, акцент и свой цвет; выбор в Alt+O, лаунчере, программе настроек.
3. Общие детали окон в двух темах.
4. Окна вещей по одному: Речі + Спорядження → Склад → Візок → Крамниця → Лавка → Скільки → Картка → Відкрити лавку и
   Моя лавка (новые пакеты) → Обмін (новые пакеты).
5. Остальной интерфейс: основной экран → Навички → Характеристики → NPC → Група → Гільдія → Вибір персонажа.
6. Файл цен с сайта и строки «ринок сайту».
7. Каждое окно — тестерам по галке, всем — после проверки и слова владельца.

## Решено по вопросам проверки (владелец 27.11: «этого не надо»)

- «Скляні вікна» (`[interface] uaui_glass`) — не нужны: убираем; у кого включены — обычные окна выбранной темы.
- Старые значения темы «classic» и «contrast» — не нужны: остаются две темы, тёмная и светлая; кто выбрал старые —
  переходит на тёмную.
- Не делаем: предупреждение о слишком светлом акценте, подсказку при первом открытии окна, предупреждение о продаже
  последних вещей с панели F1–F9, зени словами в обмене. (Текст на кнопке акцента — просто читаемым цветом, без
  отдельной настройки.)

## Не нужно (проверено)

- Почта и аукцион: в сервере нет их обработки — окон для них не делаем.

## Решения за исполнителем

- Точные номера и длины новых пакетов (лавка, обмен, предметы) — по правилу из «Ограничений».
- Как строится светлая тема и группы в `core/ui_theme` (правило для серых плюс точные цвета; группа — своя тема поверх
  общей).
- Формат и адрес файла цен на сайте.
- Вид «ждём ответа» на ячейке и в кошике — в стиле окон.
- Откуда текст «что даёт карта» (описания карт клиента / наш справочник) и какой звук продажи (из звуков игры).
