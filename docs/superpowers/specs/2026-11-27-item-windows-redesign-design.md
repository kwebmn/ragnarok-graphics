# Окна вещей: старая раскладка, наш вид — дизайн

Статус: предлагается (ждёт «да» владельца на этот документ). Концепт с картинками:
https://uaro.kiev.ua/docs/item-windows/ (kozak `web/docs/item-windows/`). Решения владельца ниже — решены.

## Зачем

Владелец 25.11: «у нас есть глюки с интерфейсом, особенно с покупкой, передачей вещей. и новый интерфейс хотя и
выглядит современно но имеет набор проблем и для новых игроков не очень удобен». 27.11: «они привыкли к старым
интерфейсам, надо продумать такой интерфейс в котором он был как старый но с новыми возможностями и он должен не
глючит».

Жалобы игроков на эти окна: R-DBGBHJ «в новом интерфейсе не могу купить», R-AR8CRT «не могу прочитать описание
предметов», R-WP985Q «непонятные символы в карточке», R-WVP27C «долго грузится склад». С середины октября — 99
исправлений, 22 из них про перенос вещей; причина — два хозяина у каждого действия (наше окно и окно игры).

## Цели

- Каждое окно вещей — по раскладке и поведению как в старом клиенте (kRO 2007): где что лежит, перетаскивание,
  двойной клик, правый клик — описание, окно «скільки».
- Новое встроено в окно и видно новичку: кнопки и строка-подсказка клавиш внизу окна, а не только скрытые клавиши.
- У действия один хозяин — наш слой: действие уходит нашим пакетом, результат — из ответа сервера. Окно показывает
  то, что сказал сервер.
- Две темы — тёмная и светлая — для всего нашего интерфейса; тёмная по умолчанию.

## Не цели

- Сервер игры не меняем (другой программист).
- «Современный» вид не делаем; окна, не связанные с вещами, перерисовываем только темой (их раскладка не меняется).

## Чего нельзя допустить

- Потерять или удвоить вещь или зени из-за нашего окна.
- Две копии правды: окно игры и наше одновременно действуют над одной вещью.
- Новичок не находит действие, которое раньше делалось в старом окне.

## Ограничения

- Клиент kRO Sakexe 2007-05-07. Номер и длина каждого пакета — из `/root/uAthena/db/packet_db.txt` для версии нашего
  клиента и сверяются с журналом отправок самой игры. Ядро уже есть: `core/item_packets`, `core/item_state`,
  `core/item_actions`, `win/item_net` (бета 3.0.24-beta.4–.18).
- Окна — uaUI (RmlUi), разметка RML руками, проверка парсером; ширины в % — border-box; без SetProperty каждый кадр.
- Тексты на трёх языках в `core/settings/strings.cpp`; слова окон — на языке игры.
- Каждое окно — своя галка; новое сначала у тестеров («Перевіряємо зараз»), всем — после проверки и слова владельца.
- Пад управляет каждым окном (как сейчас: вкладки, ячейки, A/B/X/Y).
- Слабые видеокарты: без размытия фона и тяжёлых теней.
- Размер — от масштаба интерфейса (как остальные наши окна).

## Подходы

1. **А. «Как в игре, только чётко»** — картинки старых окон из файлов клиента в высоком разрешении. Отброшен
   владельцем.
2. **Б. Старая раскладка, наш вид** — **выбран владельцем 27.11.** Расположение и поведение старых окон, цвета и
   шрифты нашего интерфейса, две темы.
3. **В. Окна самой игры + наша полоска кнопок** — отброшен: мелко, мягко, новое не помещается.

## Решено владельцем

27.11, первый круг: способ Б; вкладки — наши шесть (усе / витратне / спорядж. / карти / різне / обране) вертикально
слева; размер — от масштаба интерфейса; слова — на языке игры; темы тёмная и светлая на выбор. Затем: «и остальные
интерфейсы тогда надо сделать на ... светлую тему» — светлая тема для всего интерфейса.

27.11, второй круг:
1. Продажа NPC: «обране» в список продажи не попадает; вещь с картой — всегда спрашиваем; с заточкой +5 и выше —
   спрашиваем.
2. Цены с рынка сайта (в «Відкрити лавку» и в картке): программа настроек раз в день скачивает с сайта небольшой файл
   средних цен.
3. Обмін: красной рамкой — то, что другой игрок положил за 5 с до своего «Готово» (в RO вещь из обмена не убрать,
   только отменить обмен; зени, выставленные за эти 5 с, — тоже красным).
4. Моя лавка: последний покупатель и тихий звук при продаже.
5. Тема для новичков по умолчанию — тёмная.
6. Скільки штук: кнопки 1 / 10 / половина / усе.

## Общие детали (один раз для всех окон)

- Заголовок: название на языке игры, клавиша окна (Alt+E…), ×. Строка-подсказка клавиш внизу окна.
- Вертикальные вкладки слева (шесть), поле поиска под заголовком, ячейки с числом, пометка «нове».
- Нижняя полоса: вес / места / зени с полоской заполнения (красная, когда почти полно).
- Кнопки: главная (золото в тёмной, синяя в светлой), обычная, опасная (красная рамка).
- Список строк: значок, название, подпись, цена справа, «− N +».
- Окно «скільки» и картка вещи — общие для всех окон.

## Окна

Для каждого: как в старом → новое. Пакеты — семантика; номера по правилу из «Ограничений».

**Речі + Спорядження.** Сетка, вкладки; «Спорядження» вплотную слева, двигаются вместе (решено 31.10); слоты по
местам старого окна, фигурка, стрелы, комплекты 1/2/3. Новое: поиск, «нове», вес и зени внизу, подсказка клавиш.
Действия: использовать, надеть, снять, выбросить — нашими пакетами (последний этап «через пакеты»).

**Склад.** То же окно, что «Речі». Новое: выбор нескольких (Ctrl/Shift) и «Забрати вибране (N)», Alt+ПКМ — вся
пачка, места. Пакеты есть (0x0094 / 0x00f7 / 0x0193).

**Візок.** То же окно; вес тележки, «Відкрити лавку». Новое: красная полоса, когда почти полна; склад ↔ візок
напрямую. Пакеты есть (0x0126–0x0129).

**Крамниця NPC: купити.** Список и кошик рядом. Новое: поиск, клик 1 / Shift 10 / ПКМ картка, «залишиться», вес после
покупки, отказ с причиной. Пакеты есть (0x00c8 / 0x00ca).

**Крамниця NPC: продати.** Ваши вещи слева, что продаёте справа. Новое: «обране» не попадает; карта — спрашиваем;
заточка +5 и выше — спрашиваем; вся вкладка «Різне» кнопкой; двойной клик — вся пачка. Пакеты есть (0x00c9 / 0x00cb).

**Лавка торговця.** Список и кошик. Новое: ПКМ — картка с картами и заточкой, вес после покупки, отказ с причиной.
Пакеты есть (0x0134 / 0x0135).

**Відкрити лавку.** Тележка слева, лавка справа: название, цена, количество, «N з M місць». Новое: подсказка цены с
рынка сайта, цены запоминаются. Пакет открытия лавки — новый.

**Моя лавка.** Что выставлено, «Закрити лавку». Новое: продано N из M, «усе», заработано с налогом сервера (2 %,
`vending_tax 200`), последний покупатель (сервер шлёт «%s has bought your item(s).», `buyer_name: yes`), тихий звук.
Пакеты: отчёт о продаже, закрытие лавки — новые.

**Обмін.** «Віддаєте» | «отримуєте», зени под каждым, «Готово» (замок) → «Обмін». Новое: красная рамка и строка на
том, что другой положил (и зени, что выставил) за 5 с до своего «Готово»; картка по наведению; зени с пробелами.
Пакеты обмена — новые (этап «Обмін»).

**Скільки штук.** Число, Enter — да, Esc — нет; кнопки 1 / 10 / половина / усе; предел по весу и месту; пусто + Enter
— всё. Уже есть свой режим (`askcardwin::askCount`, 3.0.24-beta.7).

**Картка речі.** Картинка, свойства, описание, гнёзда. Новое: что даёт каждая карта, свободные гнёзда, цена у NPC и
на рынке сайта.

## Темы

- Одна настройка для всего нашего интерфейса: существующая `[interface] theme` (`core/ui_theme`: standard | classic |
  contrast) получает значение «світла»; тёмная (standard) — по умолчанию. Цвета всех окон проходят через тему
  (`themedCss`), поэтому остальные окна получают светлую тему тем же путём.
- Светлая: фон окна #f6f8fc, ячейки белые, линии #cbd3e2, текст #181c26, акцент синий #2f5fd0.

## Цены с рынка сайта

- Сайт отдаёт файл средних цен (по продажам в лавках и на рынке сайта за последнее время): номер вещи → средняя цена,
  число сделок. Программа настроек скачивает его раз в день в папку данных; игра только читает файл (в ddraw.dll нет
  сети). Нет файла или вещи в нём — строки «ринок сайту» нет.

## Порядок

1. Проверить в игре пакеты «Складу», «Візка», «Крамниці», «Лавки».
2. Общие детали в двух темах + светлая тема в `core/ui_theme` для всего интерфейса.
3. Окна по одному в новом виде: Речі + Спорядження → Склад → Візок → Крамниця (купити, продати) → Лавка → Скільки →
   Картка → Відкрити лавку и Моя лавка (с новыми пакетами) → Обмін (с новыми пакетами).
4. Файл цен с сайта и строки «ринок сайту».
5. Каждое окно — тестерам по галке, всем — после проверки и слова владельца.

## Решения за исполнителем

- Точные номера и длины новых пакетов (лавка, обмен, предметы) — по правилу из «Ограничений».
- Как именно строится светлая тема в `core/ui_theme` (правило для серых плюс точные цвета).
- Формат и адрес файла цен на сайте.
- Вид «ждём ответа» на ячейке и в кошике — в стиле окон.
- Откуда текст «что даёт карта» (описания карт клиента / наш справочник — как сейчас в картке) и какой звук продажи
  (короткий из звуков самой игры).
